# 设计说明（DESIGN / PRODUCT）

## 产品定位

**Windows 单用户的本地机会工作台**：在桌面上长时间对比「选品机会 ↔ 货源/许可 ↔ 价格信号」，判断"下一步该核验什么"。
它是**工作工具**，不是营销页、不是验收报告：首屏给结论与动作，细节可展开，原始文件路径与技术日志收进"采集来源"与行内证据。

## 用户与场景

- 单人、桌面浏览器（1440×900 起），也会在手机上快速翻看（390×844）。
- 关注：可读性、证据可追溯、操作效率；反感：数字堆砌、假分、虚构中文摘要、假装实时。
- 典型动作：按平台/关键词缩小范围 → 看评分构成与证据 → 打开原始链接 → 记录核验结论。

## 信息架构

| 页面 | 首要问题 | 主要动作 |
| --- | --- | --- |
| 总览 `/` | 现在最该核验哪一条？ | 打开机会榜、看联动 Top5 |
| 机会 `/opportunities` | 这批线索怎么排？ | 关键词/平台/最低分筛选、按评分/需求/毛利排序、展开证据 |
| 货源 `/sources` | 哪些货源能用、许可什么条件？ | 许可筛选、展开许可理由、看价格信号与联动口径 |
| 采集来源 `/collect` | 数据是哪来的、新不新？ | 看文件状态/坏行/mtime、筛平台样本 |
| 每日快照 `/daily` | 这一批的总体情况？ | 读批次计数与许可分布 |

## 设计系统

**色彩**（冷中性 + 克制蓝，语义只用文字+浅色 chip，不用粗彩色左边框）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f5f7fa` | 页面底 |
| `--panel` | `#ffffff` | 面板 |
| `--ink` / `--ink-2` | `#101828` / `#344054` | 正文 / 次级 |
| `--muted` | `#5b6778` | 辅助文字（白底对比 ≈4.9:1） |
| `--line` | `#d5dbe3` | 分隔/边框 |
| `--accent` | `#1d4ed8` | 主按钮、链接、当前导航 |
| `--ok` / `--warn` | `#067647` / `#8a4b00` | 可商用 / 需授权、待核验 |

**字体与排版**：系统字体栈（Segoe UI / 微软雅黑 / PingFang SC）；正文 15px / 1.6；表格 13.5px；标题 18/15.5/15；数字用 `font-variant-numeric: tabular-nums`。
**间距与形状**：8px 基准，面板 padding 18px，圆角 10px（chip 999px），阴影仅 `0 1px 2px rgba(16,24,40,.06)`。
**布局**：左侧 232px 深色导航（品牌 + 五页 + 数据摘要）+ 右侧顶栏（页标题 + 快照时间）+ 内容 + 页脚。≤900px 时侧栏结构折叠为顶部按钮控制的可折叠列表。

## 组件

- **数字条**（`.stat-strip`）：4 个横向紧排指标，非七张等大卡片；每项"标签/数值/注脚"。
- **首屏线索**（`.lead`）：左侧标题+平台/评分 chip+下一步；右侧 3 个关键比值 + 主按钮。
- **筛选栏**（`.filters`）：`GET` 表单，`关键词 / 平台 / 许可 / 最低分` 组合；右侧实时"筛后 N / 共 M"与"清空条件"；排序通过表头链接切换并保留其它条件。
- **表格**：唯一重元素；容器内横向滚动；标题列用 `<details>` 展开证据（原始链接、评分构成、毛利假设、成本说明、原始引用）。
- **状态**：`可用/缺失`、`可商用/需授权/未知`、`未评估`、`估算/待价格核验` 一律文字 chip；空结果给"没有符合条件…试试清空条件"。
- **折叠**：`.evidence` 仅在展开时出现；`details summary` 自带"展开/收起"提示。

## 交互原则

1. **真实**：所有筛选/排序/计数在服务端生效（`GET` 参数），刷新等于重读文件；没有"假装可用"的按钮（无采集触发、无写操作按钮）。
2. **可回溯**：每行可展开到原始 URL 与 `raw_ref`；界面不复制数据文件，不生成摘要。
3. **诚实状态**：无数据/文件缺失/坏行 → 显式提示；可售性未就绪 → `未评估`；价格口径在货源页显式展示。
4. **克制动效**：仅 hover 背景与 `prefers-reduced-motion` 下全部关闭。

## 无障碍

- 跳过链接（`.skip` → `#main`）、`aria-current="page"`、`aria-expanded`（移动导航）、`role="status"`（筛后计数、空状态）。
- 表单控件均被 `<label>` 包裹（含可见文字），`type=search/number` 语义正确。
- 可见 focus ring：`outline: 2px solid var(--accent); outline-offset: 2px`。
- 颜色不是唯一信息载体（许可结论同时有文字与 SPDX 代号）。
- 正文对比度：`#101828`/`#fff` ≈ 15.5:1，`#5b6778`/`#fff` ≈ 4.9:1（≥4.5:1）。

## 技术取舍

- **不引入模板引擎文件**：五页由 `app.py` 的 `layout()` 统一生成，保证同一设计系统、零额外依赖、易审查。
- **不 import `app` 包**：以文件路径加载 `app/dash/data.py`，避免 `create_app/ensure_schema` 触碰业务库。
- **无 CDN / 无外部字体 / 无图标库**：全部本机静态资源，离线可用。
