# 平台准入核对清单（闲鱼类目 / 资质）

> 面向非技术用户。**本轮不替你判断平台是否允许**，只给“去哪里看、看到什么算确认、怎么留证、怎么登记”。
> 核对完成前：**`platform_evidence` 保持为空**，工作台导出会一直 **409**（这是设计，不是故障）。
> 留证文件命名：`yyyyMMdd-序号-内容`，例如 `20261024-01-类目页截图.png`、`20261024-02-发布规则条款.md`。
> 每条记录**日期 + 页面标题 + 链接或文件名**；截图请不要含你的账号、手机号、订单号等个人信息（可打码）。

## 0. 先准备一个留证文件夹

```
docs/validation/product-workflow/b23/evidence/
  20261024-01-类目页截图.png
  20261024-02-发布规则.md
  ...
```
（文件名示例为虚构；用你自己的真实文件名。）

## 1. 五个核对点

### ① 最接近的类目名称与路径

- **在哪里看**：闲鱼发布页 → 选择类目 → 搜索你商品的关键词（例如「学习计划」「Excel 模板」「文档模板」）。
- **看到什么算确认**：能记录下**完整路径**，例如「学习/办公 → 文档模板」或「教育培训 → 学习资料」；并记下该路径下**是否明确出现“虚拟商品/电子文件”字样**。
- **留证**：类目选择页截图（含面包屑路径）+ 页面标题。
- **常见误区**：只看到搜索联想词就当成类目；路径要能一层层点到。

### ② 该类目是否允许虚拟商品 / 文件交付

- **在哪里看**：该类目的发布须知 / 平台《发布规范》里关于“虚拟商品、电子文件、网盘交付”的条款。
- **看到什么算确认**：找到**明确允许**或**明确禁止**的原句；只写“遵守平台规则”这类空话不算确认。
- **留证**：条款原文截图或另存网页文本（记录段落标题与条款编号，如有）。
- **常见误区**：把“实物类目”里挂电子文件当作允许——那通常是违规。

### ③ 是否需要资质、保证金或类目权限

- **在哪里看**：发布页的“资质/权限”提示、类目申请入口、平台规则里关于“出版物经营许可、实名、保证金”的条款。
- **看到什么算确认**：明确写出**需要什么**（如实名认证、出版物经营许可证、保证金金额）或**明确不需要**。
- **留证**：提示截图 + 条款链接；若需要证件，只记录“需要哪类证件”，**不要上传证件照到本仓库**。
- **常见误区**：以为“个人号能发”就等于“不需要资质”。

### ④ 对价格、交付方式、售后的限制

- **在哪里看**：类目规则 / 平台交易规则中关于“最低价、虚拟商品交付时限、退款与售后”的条款。
- **看到什么算确认**：能写出具体限制（例如“虚拟商品需在 X 小时内交付”“不支持七天无理由”），或明确“无额外限制”。
- **留证**：条款截图或链接 + 记录日期。
- **常见误区**：用别的类目的规则套到自己类目。

### ⑤ 该类目常见违规样例

- **在哪里看**：平台规则中的“违规处理/典型案例”章节，或类目页的“违规提醒”。
- **看到什么算确认**：至少记录 **2 条**与本商品相关的违规样例（如“虚假宣传效果”“诱导站外交易”“出售他人版权模板”）。
- **留证**：条款截图/链接；把与本案相关的句子抄进 `PLATFORM-DECISION.md` 的备注。
- **常见误区**：只记“禁止违规”这种泛泛表述。

## 2. 核对完成的判定

五条**全部**有“看到什么”的具体结论 + 至少一份可指认的留证（链接或文件名），才算核对完成。
任一条只能写“没找到/不确定”，就**视为未完成**，`platform_evidence` 继续保持为空。

## 3. 填回工作台（只填证据，不填结论）

- 打开 `/copy?wo=<你的单号>` → **目标平台条件证据**，填**条款链接**或**截图编号/文件名**（例：`20261024-01-类目页截图.png`）。
- 保存后七项里的 `platform` 会转通过——这**只代表“有证据”**，不代表平台已批准，也不代表可以立刻发布。
- 结论请写在下面的模板里，由**你本人**签字/记录。

## 4. 常见问题

| 问题 | 回答 |
| --- | --- |
| 找不到类目怎么办？ | 记“未找到”，不要硬选一个相近的实物类目；先按 ③ 问平台客服或看规则。 |
| 条款是“以平台审核为准”怎么记？ | 原句抄下来 + 链接 + 日期，结论写“需资质/待确认”，不要写成“允许”。 |
| 能不能先填一个链接让导出通过？ | 不建议。填了不实链接只是让页面变绿，发布时仍会被平台拒；本清单要求能指认的原文。 |
| 截图要打码吗？ | 要。账号、手机号、订单号、地址都打码；只保留类目路径与条款文本。 |
