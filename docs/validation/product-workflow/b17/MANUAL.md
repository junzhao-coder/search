# 从 0 到发布：机会工作台操作手册

> 给谁看：没有技术背景、但愿意按步骤点鼠标的人。
> 你不需要懂代码；你只需要一个浏览器。**发布动作由你在闲鱼上完成**，工作台只记录证据与结果。
> 本手册不承诺收益，也不替你做平台确认、审核判断或发布。

## 0. 开始前：把工作台打开（1 分钟）

1. 打开工作台所在文件夹，双击 **`start_workbench.cmd`**。
   - 或者在命令行里执行：`python tools\workbench\run.py --port 5015`。
2. 浏览器打开 **http://127.0.0.1:5015** ，点左侧导航的 **「商品工作单」**。
3. **成功标志**：从**正确入口**进来——左侧导航能看到「总览 / 机会线索 / 教程与内容 / 商品工作单 / 货源与价格 / 采集来源 / 每日快照」，点「商品工作单」后页面标题是「商品工作单」，列表里的单能点开详情页。
   - 顶部那行计数（**本次观察值**：`机会 60 · 货源 14`、`价格信号 20 · 联动 10`）会随数据更新变化，**不作为启动成功的判据**，只作"数据已加载"的参考。
4. **常见错误**：
   - 打不开 → 先看命令行窗口有没有报错；端口被占用（提示"已被占用"）就换端口：`python tools\workbench\run.py --port 5016`，地址相应改成 5016。
   - 页面能开但没数据 → 确认你是从这份工作区启动的（`healthz` 里 `root` 应指向本工作区）。

> 说明：工作台是**只读本地文件**的界面，不会写业务库；它把"证据"写进自己的工作库（`tools/workbench/runtime/workflow.sqlite3`）。

## 环节 1｜新建自制商品（建单）

1. 在「商品工作单」页点 **「新建自制商品」**（或直接打开 http://127.0.0.1:5015/worksheet/new ）。
2. **填什么**（带 `*` 必填）：
   - `计划商品名 *`：例如「学习计划 Excel 模板｜课程/考试倒计时/周计划/复习进度」
   - `具体用途 *`：例如「学习计划 / 考试倒计时」
   - `拟交付物 *`：例如「Excel .xlsx 单文件（5 表 / 50 公式）」
   - 可选：`目标买家`、`格式`（xlsx/md/pdf）、`语言`、`版本`、`来源标识`（留空自动生成 `self:<名称>`）、`包含内容`、`不包含内容`、`目标平台`（本批只有「闲鱼（xianyu）」）
3. 点 **「建立工作单」**。
4. **成功标志**：跳到详情页，页头出现 `wo:yyyyMMdd-xxxxxxxx · revision 1 · 状态 待补/待货源`；列表页多出这一单。
5. **常见错误**：
   - 连点两次「建立工作单」→ 不会重复建单（同一表单重复提交会命中同一条）。
   - 目标平台选不到别的 → 本批仅支持闲鱼，这是设计如此。
   - 报"字数超限" → 商品名 1–80 字，缩短再提交。

## 环节 2｜货源候选：新增 / 导入 / 采用

> 自制商品也要建一条"货源"记录（你自己的产出就是货源）。候选只是记录，**点「采用为选定货源」才会写进工作单**。

1. 在详情页找到 **「货源候选（0）」** 区块。
2. **新增一条｜填什么**：`提供方 / 来源 *`（自制就写 `self`）、`来源链接`（自制写 `self://c3-v1` 这类标识）、`类型`（自制选「同款」）、三档许可、`许可说明`、`价格（分）`（自制填 0）、`备注` → 点 **「新增候选」**。
   - 三档许可：`可商用` / `可再分发` / `可转售`，每项都是「未记录/不明 · 允许 · 禁止」。
   - 三档怎么选：**自制**、或**已核对到明确第三方许可且满足其条件**时，才选「允许」；**不明就保留「未记录/不明」**（不要为了过检查去猜"允许"）。用了别人的素材，先取得书面许可再谈。
3. **批量导入**：把 `b2/candidates.json` 那种格式的 JSON 数组粘进 `粘贴 JSON 导入（数组）` → 点 **「导入」**（未知字段会被忽略并报告）。
4. 在候选表格的 `操作` 列点 **「采用为选定货源」**（需要带上当前 revision；替换会记事件）。
5. **成功标志**：候选行显示「已采用」；在「录入证据」区的 `货源 ID（selected_supply_id）` 和 `货源版本（supply_version）` 看到本次采用结果；「已选货源」检查项通过。「来源分组 / 来源条目 / 平台」属于原来源快照，不随采用变化。
   - 工作单顶部的「来源证据」是**选择时的快照、不可编辑**；采用新候选**不会改写它**——它记录"当初为什么选这个方向"，不是"现在的货源"。
   - **「采用」只表示你在系统里选定了这条货源，不构成任何新取得的授权。**

> **改动已选货源会作废什么（重要）**：只要这条候选是你**当前已选**的，**修改**它（改许可/价格/说明）或**停用**它，系统都会把许可**同步成新值**、把**样品证据作废**、把**成本证据作废**，导出立刻变成 **409**。**换源**（改用另一条候选）同样会作废旧样品与成本。**修改或停用"没被选中"的候选，不会影响你的证据与导出。** 恢复做法见环节 3 末段。
6. **常见错误**：
   - 只新增没采用 → 「已选货源」仍不通过。
   - 想删掉候选 → 用 **「停用」**（软删除 `is_active=0`），历史不会被删。
   - 采用时报 409 → 见 §11 的"409 版本冲突"。

## 环节 3｜样品自检（本地文件）

1. 在详情页找到 **「样品自检（本地文件）」**。
2. **填什么**：在 `文件路径（工作区内） *` 填**工作区相对路径**，例如：`docs/validation/product-workflow/b7/sample-study-planner-v1.xlsx`。
3. 点 **「执行自检」**。
4. **允许的范围**（不满足会失败）：
   - 目录：只允许 `docs/` 或 `tools/` 下面；
   - 扩展名：`.xlsx` / `.pptx` / `.md` / `.csv` / `.pdf`；
   - 大小：≤ **20MB**。
5. **它会检查什么**：`.xlsx` 读**表数 / 非空单元格数 / 公式数**，并检查**无外部链接、无 vbaProject（宏）**；**绝不执行宏或脚本**。各类型边界大致是：**xlsx＝ZIP/XML 结构计数；pptx＝页数/包结构；pdf＝只看文件头（不解析正文）；md/csv＝能否按 UTF-8 解码 + 行数/体积；`.txt` 不在本入口白名单**。
6. **成功标志**：区块顶部出现 `当前样品状态：verified` + 一行 `sample_ref`（例如 `b7:selfcheck 17/17（结构/公式自检；非真实 Excel 打开）`），就绪检查里「样品或交付入口已核验」变为「通过」。
7. **重要口径（必读）**：**当前工作台解释器未导入 openpyxl 时，会回退到 ZIP/XML 结构计数——只数结构，不计算、不渲染**。所以 `公式数` 只是"文件里有多少个公式节点"，**不等于公式在 Excel 里能算出正确结果**。自检通过 ≠ 内容正确、≠ 公式算对、≠ 授权成立；交付前请自己用 Excel/WPS 打开确认。
8. **常见错误**：扩展名不在白名单 / 超过 20MB → 被拒；xlsx 里有外部链接或宏 → 被拒；路径问题见下条。
   - **路径怎么写**：优先填**工作区相对路径 + 正斜杠**（如 `docs/validation/.../x.xlsx`）。系统实际是**按解析后的真实位置**判断文件是否落在工作区 `docs/` 或 `tools/` 内：**越界**（`../` 跳出去、或指向工作区外的位置）会被拒；而**工作区内文件的绝对路径、或 Windows 反斜杠写法，也可能被解析到同一位置后通过**。别把"建议写法"当成"强制格式"。

> **货源变更导致样品失效后，按这个顺序恢复**：① **重新自检**（同一文件再点一次「执行自检」，让 `sample_status` 回到 `verified`）→ ② **重填成本**（回「录入证据」重填 `成本（分）` 与 `成本是否已知`，保存）→ ③ **回环节 5 确认 7 项都回「通过」**（重点看第 3、4、5 项，以及导出按钮是否恢复可用）。两项没都做完之前，导出会一直是 **409**。

## 环节 4｜成本与文案录入（证据表单）

1. 在详情页往下找到 **「录入证据（填写后仍需服务端检查）」**。
2. **填什么**：逐项填（这些都是"证据字段"，不是"就绪开关"）：
   - `货源 ID`、`货源版本`（与环节 2 采用的一致）
   - `许可·可商用` / `许可·可再分发` / `许可·可转售`：三档都要「允许」才算过
   - `样品/交付入口`（未核验/核验中/已核对）+ `样品核验证据（URL/编号）`
   - `成本（分）`（整数，**100 分 = 1 元**）+ `成本是否已知`（是/否）。**采购花 0 元 ≠ 人工与售后零成本**：你的时间、答疑、退款处理都要自己算进去。
   - `目标平台条件证据`（条款 URL 或截图编号）——**这一项只能你提供**，系统不会替你填
   - `文案状态`（草稿/定稿）+ `文案版本`（如 `v1`）
   - `建议售价（分）`、`交付说明`、`售后说明`
   - `卖点（每行一条）`、`FAQ`（**JSON 数组**，两种可直接复制的写法见下）
   - **FAQ 合法写法（复制后改内容即可）**：

     ```json
     [{"q": "需要安装什么软件？", "a": "用 Excel 或 WPS 打开 .xlsx；不含宏与外部链接。"},
      {"q": "可以改课程和日期吗？", "a": "可以，改完后按使用说明调整公式区域。"}]
     ```

     暂时没有 FAQ，就填空数组：`[]`
3. 点 **「保存证据（revision N）」**。
4. **成功标志**：页面提示保存成功；`revision` 加 1；**「文案版本历史」多出一行**（版本/时间/来源/摘要）。
5. **常见错误**：
   - FAQ 不是合法 JSON → 保存被拒；请照示例格式写。
   - 文案没定稿 → 「文案定稿」不通过（`copy_status` 仍是 draft）。
   - 同一内容重复点保存 → **不新增版本**（去重）；改了内容才会生成新版本。
   - 想改回旧文案 → 用环节 8 的回滚。

## 环节 5｜就绪检查（服务端判定，7 项）

1. 在详情页找到 **「上架准备检查（服务端判定）」**。
2. **看这 7 行**（**填什么**：本环节不需要填任何东西，只核对结果；全部「通过」才算就绪）：

| # | 检查项 | 通过条件 |
| --- | --- | --- |
| 1 | 产品规格完整 | 商品名/用途/交付物/目标平台都填了 |
| 2 | 已选货源 | 环节 2 点了「采用为选定货源」 |
| 3 | 许可三档均允许 | 可商用/可再分发/可转售 都是「允许」 |
| 4 | 样品或交付入口已核验 | 环节 3 自检通过（`sample_status=verified`） |
| 5 | 成本已知 | `成本（分）>0` 或 `成本是否已知=是` |
| 6 | 目标平台条件有证据 | `目标平台条件证据` 非空（**只能你提供**） |
| 7 | 文案定稿 | `文案状态=定稿` 且 `文案版本` 非空 |

> **这七项绿灯代表什么（必读）**：它们是**按当前录入规则做的材料预检**——证明"该填的证据都有值"，**不证明**内容质量、**不证明**来源方真的给了你授权、也**不证明**平台允许你卖。第 4 项尤其：`sample_status=verified` 是**结构**核验（文件能读、表数/公式节点/无宏/无外链这些结构项通过），**不代表样品内容合格**。

> **货源一改，第 3/4/5 项会一起掉**：修改或停用**已选**货源 → 许可同步成新值（第 3 项）、样品证据作废（第 4 项）、成本证据作废（第 5 项），你会看到它们从「通过」退回「未通过」，导出变 409；**换源**同理。**改/停未选中的候选不影响**。按环节 3 末段的三步恢复后，7 项会重新对齐。

3. **成功标志**：顶部显示「已就绪」且「阻断项」为空。
4. **常见错误**：
   - 想找"标记完成/一键就绪"按钮 → **没有**，也不该有；就绪只由证据字段推导。
   - 显示「未就绪：共 7 项，未通过 1 项」+ 阻断项 → 按 §11 的顺序排查。
   - 页面上的 `待核验缺项（9）` 是**来源证据**层面的缺项，与这 7 项不是一套，别混看。

## 环节 6｜导出与记录

1. 就绪后，在「导出」区点 **「导出 Markdown」** 或 **「导出 JSON」**（未就绪时按钮显示"（未就绪）"，点了会被 **409** 拒绝）。
2. **行为说明（重要）**（**填什么**：本环节不需要填，只点两个按钮：先「导出 Markdown/JSON」，再「记录本次导出」）：
   - **GET 导出只生成内容、不写库**；
   - 必须再点 **「记录本次导出」** 才会写入导出记录（写入版本戳，供后续失效比对）。
3. **成功标志**：浏览器下载到文件；页面出现"已导出"记录行（含 revision/版本戳）。
4. **常见错误**：
   - 只点了导出、没点"记录本次导出" → 导出记录里没有这一笔（这是设计，不是 bug）。
   - 同一版本重复点"记录本次导出" → **不新增行**（去重）。
   - 导出内容里找不到成本/利润/内部备注 → 正常：导出只含**买家可见字段**（标题、卖点、内容清单、格式/兼容、价格规格、交付与售后、FAQ）。

## 环节 7｜发布回填（发布由你做，这里只记录）

1. **先在闲鱼手动发布**（见 §9 的第二件事），拿到商品链接。
2. 回到详情页 **「发布回填」** 区，**填什么**：
   - `发布状态`：未发布 / 已发布 / 已下架
   - `发布链接（http/https）`、`发布时间（文本，可留空）`、`已售数量`、`平台备注`
3. 点 **「保存发布信息」**。
4. **成功标志**：发布区显示你填的状态与链接；若状态/链接变化且之前有导出记录，页面会**提示重新核验与导出**。
5. **常见错误**：
   - 链接不是 http/https → 被拒。
   - 以为工作台会替你发布 → **不会**；这里只记录。

## 环节 8｜版本回滚（文案）

1. 在 **「文案版本历史」** 表里找到要回滚到的版本（表头：版本 / 时间 / 来源 / 摘要 / 操作）。
2. 点该行的 **「回滚」**（**填什么**：本环节不需要填，只在历史表里选一个版本）。
3. **行为说明**：回滚用旧快照**生成一个新版本**，**历史不删除**；**不回写货源/许可/成本/平台**这四类字段。
4. **成功标志**：版本历史多一行（新版本），`revision` 加 1；当前文案等于旧版内容。
5. **常见错误**：想"删掉某版本" → 不支持删除，只能回滚（历史保留是刻意的）。

## 9. 有两件事必须由你完成（系统不代做）

### 9.1 闲鱼类目与资质确认

1. 用你自己的账号登录闲鱼，进入"卖闲置/发布"页面。
2. 找**与你商品最接近的类目**（虚拟/学习资料/办公模板方向），记录：
   - 类目名称与路径（截图）；
   - 该类目对**虚拟商品/文件交付**的要求（是否允许、是否需要特定说明）；
   - 需要的**资质或认证**（如实名、保证金、类目权限），以及你当前是否满足。
3. 把**证据**留好：条款 URL 或截图编号。
4. **只有你真的做完上面的确认、手上确有条款链接或截图编号时**，才回到工作台把它填进 **`目标平台条件证据`** 并保存。**证据不足请保持待核验；填写不相干 URL 不代表材料有效**。
5. **成功标志**：确认完成、证据入库后，就绪检查第 6 项「目标平台条件有证据」才会变「通过」。注意它**只检查"有没有证据"，不判断你的证据是否充分**。
6. **注意**：工作台**不替你判断**你的账号能否发、也不替你填这一项；它是"你提供的证据"，不是系统结论。

### 9.2 实际发布与回填

1. 按平台要求发布；交付方式（站内文件/网盘等）以平台与商品页为准。
2. 发布后回到工作台做环节 7 的回填。
3. **不要**在工作台里填买家账号、密码、验证码；也不要在聊天里索取这些。
4. **成功标志**：发布区显示「已发布」+ 你的链接；导出记录与当前版本一致（如提示失效，重新导出一份并记录）。

## 10. 快速验证清单（按手册走完，应看到这 5 个状态）

| # | 看哪里 | 应该看到 |
| --- | --- | --- |
| 1 | 「商品工作单」列表 | 至少 1 条单：`wo:yyyyMMdd-xxxxxxxx`，状态 `待补/待货源` 或更新，右侧有「编辑」 |
| 2 | 详情页「上架准备检查」 | 7 行检查表；未就绪时显示"通过 N / 未通过 M"和「阻断项」；就绪时阻断项为空 |
| 3 | 详情页「导出」区 | 未就绪：按钮显示"导出 Markdown（未就绪）"、点击 409；就绪：按钮可用，且出现「记录本次导出」 |
| 4 | 详情页「文案版本历史」 | 保存文案前是 0 条；保存后 1 条；回滚后再多 1 条（历史不减少） |
| 5 | 详情页「发布回填」 | 发布状态下拉（未发布/已发布/已下架）+ 发布链接/时间/已售/备注 + 「保存发布信息」 |

> 现成示例：`wo:20261023-88ef9a66` 当前是"**未就绪**"状态——**7 项里 6 项通过、1 项未通过**，差的正是「目标平台条件有证据」，导出被 409 阻断，可用来对照第 2、3 条。但要注意：**它是演示/计划规格**，里面的规格与样品引用都是计划项，**实机内容核对与真实成本核验还没做**，别当成"已完成品"。

## 11. 故障排查表

| 现象 | 最可能原因 | 处理 |
| --- | --- | --- |
| 就绪一直不通过 | 有 1–2 项证据没填 | 按这个顺序查：**① 目标平台条件证据 → ② 已选货源 → ③ 许可三档 → ④ 样品自检 → ⑤ 成本 → ⑥ 文案定稿 → ⑦ 规格完整**；每修一项刷新看阻断项 |
| 改了/停用了已选货源，突然全红 | 改/停**已选**候选会同步许可、作废样品与成本（换源同理） | 按环节 3 末段恢复：**重新自检 → 重填成本 → 回环节 5 确认 7 项**；改/停**未选中**的候选不会有这问题 |
| 之前能导出，现在 409 | 样品/成本/许可被货源变更作废了 | 看阻断项是谁退回「未通过」，按上一条恢复；三项都回「通过」后导出自动恢复 |
| 自检失败：路径不在允许范围 | 路径不在 `docs/` 或 `tools/` 下 | 把文件移到 `docs/validation/...` 或 `tools/...` 再填相对路径 |
| 自检失败：扩展名/大小 | 不是 .xlsx/.pptx/.md/.csv/.pdf，或 >20MB | 换格式或压缩文件；照片/图片不能当样品自检对象 |
| 自检失败：xlsx 被拒 | 文件里有**外部链接**或**vbaProject（宏）**等实际检查项；**没有公式的正常模板也能通过**（0 公式本身不是被拒理由） | 在 Excel 里"编辑链接→断开"、另存为无宏 `.xlsx`；具体以页面报的检查项为准 |
| 自检通过但公式在 Excel 里不对 | 自检是**结构计数**，不计算、不渲染 | 用 Excel/WPS 打开确认；必要时按 F9 重算。**别把自检通过当成"公式算对了"** |
| 提示"路径被拒/非法路径" | **解析后的真实位置**不在工作区 `docs/` 或 `tools/` 内（如 `../` 跳出、或指向工作区外） | 换成工作区内文件的路径；推荐相对路径 + 正斜杠。工作区内文件的绝对路径/反斜杠**也可能可用**，被拒时先查是否越界 |
| 提交时好一顿然后报错/回到表单 | 页面放太久，**CSRF 令牌失效** | 刷新页面（F5）重新填提交；不要用同一个旧标签页反复提交 |
| 保存报 **409** | 页面上的 `revision` 已过期（别处改过这单） | 刷新页面拿最新 `revision`，重新填这次改动（表单按钮上会写 `revision N`） |
| 重复点"建立工作单"，担心建了两单 | 同一表单重复提交**不会**重复建单 | 去列表看，只有一条即正常 |
| 重复点"记录本次导出" | 同版本**去重**，不新增行 | 正常；改了内容/版本才会新增 |
| 点了导出，记录里没有 | 导出 **GET 只生成、不写库** | 再点「记录本次导出」 |
| 发布后页面提示"重新核验/重新导出" | 状态或链接变了，旧导出的版本戳失效 | 按提示重新核对证据并重新导出一份、记录 |

## 13. 术语与边界

- **工作单（wo:…）**：一个商品从"想法"到"发布记录"的一张表。
- **revision**：这张表的版本号；每次保存会加 1，用来防止"你改了、别人也改了"的覆盖。
- **证据字段**：货源、许可、样品、成本、平台条件、文案——它们由**你**提供，系统只做判定。
- **不代做**：系统不替你确认平台类目/资质，不替你发布，不替你填平台条件。
- **不承诺**：本手册与工作台都不承诺收益、销量、排名，也不对平台审核结果作任何保证。
- **不改你的原始数据**：评分/货源原始 CSV、业务库、`CONTRACT` 均不因使用本流程而变化。

## 14. 已知限制（如实说明）

1. **自检只到结构层**：当前工作台解释器未导入 openpyxl 时回退 ZIP/XML 结构计数，**不计算、不渲染**；`公式数` 只是公式节点数，不保证在 Excel 里算对。**交付前请自己打开验证**。
2. **平台侧未核**：闲鱼类目、资质、虚拟交付规则都需要你自己确认并留证；本手册不给结论。
3. **未真实发布**：本手册编写期间没有登录平台、没有发布、没有采购；发布回填字段的实际效果需你首次发布后验证。
4. **示例单是演示/计划规格**：`wo:20261023-88ef9a66` 6 项通过、1 项未通过（差平台条件），适合练手对照；它的内容与成本都还是计划项，**实机内容与真实成本核验仍待做**，不要当成"已可上架"。
5. `待核验缺项（9）` 是来源证据层面的旧口径计数，与就绪 7 项不是同一套指标。
