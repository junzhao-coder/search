# A 路线：Notion 学习笔记模板 — 规格草案

> **草案：本文未验货、未定价、未上架。** 许可结论引用 B2（`../b2/candidates.json`、`../b2/REPORT.md`），不替代法律意见。本文是 A 路线（自制）的搭建规格，不含成品、不含 UI 美化包、不含自动化脚本/客服代做。
> 关联：[DECISION.md](DECISION.md)（三路对照）、[copy-draft.md](copy-draft.md)（文案骨架）；就绪口径见 [B3 REPORT](../b3/REPORT.md) 与 [readiness.py](../../../../tools/workbench/readiness.py)。

## 0. 目标与最小可交付

- **目标买家**：使用 Notion 的学生、自学者；希望把“课程—课堂笔记—复习—作业”放在一个可复制页面里的用户；不要求复杂自动化。
- **最小可交付**：一个可复制到买家 Notion workspace 的**学生笔记模板**，含 7 个页面、4 个数据库、7 个视图、3 个核心页面模板（另含作业检查清单正文）与合成示例数据；买家可自行改课程名/学期/笔记。
- **语言/版本**：中文界面为主，字段名可保留英文括注；模板版本 `a-v1`（草案，未发布）。
- **不含**：UI 美化包、封面/图标设计服务、自动化脚本/AI 生成、客服代做、第三方模板/字体/图片、持续更新、效果或收益承诺。

## 2. 数据库与字段（4 个数据库，38 个属性）

### 2.1 Courses（课程库，9 个属性）

| 属性 | 类型 | 选项/说明 |
| --- | --- | --- |
| 课程名称 | Title | 必填 |
| 学期 | Select | `2026 秋`、`2026 春`、`其他`（可增） |
| 教师 | Text | 可空 |
| 上课时间 | Text | 如“周一 3–4 节”；不做日历同步 |
| 课程目标 | Text | 1–3 句 |
| 状态 | Select | `进行中`、`已完成`、`暂停` |
| 课堂笔记 | Relation → Lectures | 反向关联到课程 |
| 作业 | Relation → Assignments | 反向关联到课程 |
| 待复习数 | Rollup（可选） | Count Review where 完成=未勾选；Notion 套餐不支持则省略 |

### 2.2 Lectures（课堂笔记，11 个属性）

| 属性 | 类型 | 选项/说明 |
| --- | --- | --- |
| 课堂标题 | Title | 如“矩阵乘法” |
| 课程 | Relation → Courses | 必填 |
| 日期 | Date | 上课日期 |
| 周次 | Select | `1`…`16`（按学期建选项） |
| 主题 | Text | 本节主题/章节 |
| 关键概念 | Multi-select | 自定义，如“秩”“特征值” |
| 疑问 | Text | 未解决的问题，供复习 |
| 复习状态 | Select | `未复习`、`复习中`、`已复习` |
| 下次复习 | Date | 由复习节奏手动/模板填入 |
| 关联复习 | Relation → Review | 反向关联 |
| 附件 | Files | 课件/图片；买家自行上传，模板不附带第三方文件 |

### 2.3 Review（复习队列，9 个属性）

| 属性 | 类型 | 选项/说明 |
| --- | --- | --- |
| 复习项 | Title | 如“矩阵乘法：条件—结论” |
| 来源课堂 | Relation → Lectures | 必填 |
| 复习日期 | Date | 计划复习日 |
| 轮次 | Select | `当天`、`1 天`、`3 天`、`7 天`、`14 天` |
| 掌握度 | Select | `生疏`、`一般`、`熟练` |
| 问题 | Text | 主动回忆的问题 |
| 答案 | Text | 答案/要点 |
| 完成 | Checkbox | 勾选即完成本次复习 |
| 备注 | Text | 错因/补充 |

### 2.4 Assignments（作业与 DDL，9 个属性）

| 属性 | 类型 | 选项/说明 |
| --- | --- | --- |
| 作业/考试 | Title | 必填 |
| 课程 | Relation → Courses | 必填 |
| 类型 | Select | `作业`、`小测`、`考试`、`项目` |
| 截止日期 | Date | 必填 |
| 状态 | Select | `未开始`、`进行中`、`已提交`、`已完成` |
| 权重 | Number | 百分比；可空 |
| 备注 | Text | 提交方式/范围 |
| 关联课堂 | Relation → Lectures | 可选 |
| 提醒日期 | Date | 可选，手动查看；不承诺自动提醒 |

## 3. 视图（7 个）

| # | 数据库 | 视图名 | 类型 | 配置 |
| --- | --- | --- | --- | --- |
| 1 | Courses | 课程总览 | Table | 显示 课程名称/学期/状态/待复习数；按学期分组 |
| 2 | Lectures | 按周 | Board 或 Table | Group by `周次`；Sort `日期` 升序 |
| 3 | Lectures | 按课程 | Board 或 Table | Group by `课程`；Sort `日期` 降序 |
| 4 | Lectures | 本周课程 | List/Table | Filter `日期` is within `This week`；Sort `日期` |
| 5 | Review | 未复习 | Table | Filter `完成` unchecked；Sort `复习日期` 升序 |
| 6 | Review | 待复习 | Table | Filter `下次复习` is on or before `Today`；Sort 升序 |
| 7 | Assignments | 作业 DDL | Table | Filter `状态` is not `已完成`；Sort `截止日期` 升序 |

> 视图只依赖 Notion 内置 filter/sort/group；不使用公式自动化。若买家套餐不支持 Board/Group，页面保留 Table 版本。

## 4. 页面模板/按钮与关联

### 4.1 数据库模板（不是自动化）

- **课程模板**（Courses）：新建课程时生成正文“学习目标 / 考核方式 / 常用链接 / 备注”。
- **课堂模板**（Lectures）：新建课堂时生成正文：
  1. 本节目标
  2. 课前问题（2–3 个）
  3. 关键概念（与属性 `关键概念` 对应）
  4. 例子/推导
  5. 课堂记录
  6. 疑问（同步到属性 `疑问`）
  7. 一句话总结
  8. 复习卡入口（提示在 Review 新建，不自动生成）
- **复习卡模板**（Review）：正文“问题 / 答案 / 出处 / 错因”；属性填 `来源课堂`、`轮次`、`掌握度`。
- **作业模板**（Assignments）：正文“要求 / 提交方式 / 拆分步骤 / 检查清单”。

> 这些是 Notion database template（页面模板），不是按钮自动化；不包含脚本、API、AI、定时任务。

### 4.2 关联

- `Courses.课堂笔记 ↔ Lectures.课程`（一对多）
- `Courses.作业 ↔ Assignments.课程`（一对多）
- `Lectures.关联复习 ↔ Review.来源课堂`（一对多）
- 可选 rollup：Courses `待复习数` = Review 未完成计数；不支持 rollup 时由“未复习”视图人工查看。

## 6. 学生每周使用流程（建议）

1. **周日 10 分钟**：在 `本周课程` 看下周课程；在 `作业 DDL` 看截止日；把本周 `周次` 填好。
2. **课前**：用课堂模板新建一条；写 2–3 个课前问题；关联课程。
3. **课中**：在正文记录关键概念/例子；属性填 `关键概念`、`疑问`。
4. **课后 24 小时内**：补一句话总结；从笔记中挑 1–3 个点，在 Review 建复习卡（问题/答案）。
5. **每天 5–10 分钟**：打开 `未复习`/`待复习`，按 1/3/7/14 天轮次复习；勾选 `完成`，更新 `掌握度`。
6. **每周复盘**：用 `按课程` 看每门课笔记是否缺失；用 `按周` 看本周覆盖；未解决的 `疑问` 进入下周课前问题。
7. **期末**：按课程筛选笔记/复习卡，导出或归档；不承诺自动生成复习计划。

## 7. 目标买家与卖点（与 copy-draft 对齐）

- **买家**：Notion 初学者/学生/自学者；需要“课程—笔记—复习—作业”一条线，但不想自己设计数据库。
- **卖点 1**：4 个数据库 + 3 组关联，课程/课堂/复习/作业不散落（§2/§4）。
- **卖点 2**：按周/按课程/未复习/待复习/DDL 视图，打开就能用（§3）。
- **卖点 3**：课堂模板 + 复习卡模板 + 作业模板，减少每次从空白页开始（§4.1）。
- **卖点 4**：含合成示例数据和一周使用流程，复制后可照着改（§5/§6）。
- **卖点 5**：交付形态明确：Notion Duplicate 链接优先，或导出文件（§8）；不承诺自动同步/自动提醒。

> 文案见 [copy-draft.md](copy-draft.md)；每条卖点都对应本节/上述章节，不写无法由规格证明的量化效果。

## 8. 交付形态与最小范围

### 8.1 交付形态（二选一，最终以商品页为准）

1. **Notion Duplicate 链接**（优先）：模板放在独立页面，开启“允许复制为模板”；买家在自己的 workspace 点 Duplicate。需要买家有 Notion 账号；链接权限/可复制设置需交付前自测。
2. **Notion 导出文件**（备选）：导出 Markdown/HTML/CSV；**关系/视图/rollup 可能丢失或降级**，需在商品页明确“导出件不保证与 Notion 内完全一致”。不把导出件冒充完整模板。

### 8.2 最小可交付（必须）

- 7 个页面、4 个数据库、38 个属性、7 个视图、3 个核心页面模板（课程/课堂/复习卡；另含作业检查清单正文）、合成示例数据；
- `00 开始使用` 含复制步骤、字段说明、版本、包含/不包含；
- 至少完成一次“空白 workspace Duplicate → 关系/视图可用”的自测（当前**未执行**，草案）；
- 所有文字/示例自制；不使用第三方模板页面、字体、图标、图片；如使用，必须替换或取得许可。

### 8.3 明确不含

- UI 美化包、封面设计、图标包、动画；
- 自动化脚本、API、AI 生成、定时提醒、自动导出；
- 客服代做、代录入、代整理笔记；
- 第三方模板/资料/字体/图片（除非另行授权并标注）；
- 持续更新、效果保证、收益承诺、平台审核结果承诺；
- 真实学校/教师/个人信息。
