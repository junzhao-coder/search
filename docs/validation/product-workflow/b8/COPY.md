## 2. 卖点（5 条，逐条对应 v1 或差异方案）

1. **一个 .xlsx 放 5 张基础表**：使用说明、课程与考试、考试倒计时、周计划、复习进度；50 个公式，打开即可改课程/日期。  
   → 对应 v1（B7 REPORT §4）；不是多个 App/订阅。
2. **考试倒计时自动算**：`考试倒计时` 用 `=TODAY()` 和 `IF` 计算剩余天数，并分“已过期/紧急/临近/正常”四档；不需要手算。  
   → 对应 v1 `考试倒计时` 的 `TODAY`/`IF` 公式（B7 REPORT §4）。
3. **期末冲刺版多一张“每日任务”表**：`冲刺日计划` 用 `IF`/`TODAY`/`COUNTIF` 显示倒计时、状态、完成率，把“还有几天”落到“今天做什么”。  
   → 对应 [DIFFERENTIATION.md](DIFFERENTIATION.md) §2；规划版本，未制作。
4. **考研/四六级版多一张“英语分项”表**：词汇/听力/阅读/写作/翻译分项填计划量、已完成、正确率，`IF`/`AVERAGE` 自动算完成率和状态。  
   → 对应 DIFFERENTIATION §3；规划版本，未制作。
5. **学期周计划版多一张“课程表”并提示冲突**：`COUNTIFS` 对“星期+时段”计数，>1 显示“冲突”，再配合 v1 的 `周计划` 使用。  
   → 对应 DIFFERENTIATION §4；规划版本，未制作；冲突只提示，不自动改课。

> 每条卖点都能在 v1 或差异方案中找到具体表/公式；不写无法证明的效果承诺。

## 5. FAQ（6 条，草案/待验货）

**Q1：需要安装什么软件？**  
A：用 Excel 或 WPS 打开 `.xlsx`；不含宏、外部链接，不需要安装插件。手机/平板可打开，但打印/下拉体验以桌面为准。

**Q2：怎么交付？**  
A：计划交付 `.xlsx` 文件（站内文件/网盘等方式以平台和商品页为准）；当前未上架，具体方式未定。

**Q3：可以改课程、考试日期和复习项吗？**  
A：可以。改 `课程与考试` 的课程/日期；`考试倒计时` 自动取数；`复习进度` 按知识点填。增删行后按 `usage.md` 调整公式区域。

**Q4：里面具体有什么？**  
A：v1 是 5 张表 + 50 个基础公式 + 示例数据；三场景规划各加 1 张表（冲刺日计划/英语分项/课程表）。差异见 [DIFFERENTIATION.md](DIFFERENTIATION.md)；规划版本未制作。

**Q5：能保证学习效果或提分吗？**  
A：不能，也不作此类承诺。模板只提供表结构、公式和打印版式；学习效果取决于使用者。平台规则也禁止虚假/夸大宣传（见 [PLATFORM-RULES.md](PLATFORM-RULES.md)）。

**Q6：会更新吗？售后怎么算？**
