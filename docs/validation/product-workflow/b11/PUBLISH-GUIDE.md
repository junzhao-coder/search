# 闲鱼上架操作指引（用户手动完成）

> **“上架”永远由你手动完成**；本文只给可粘贴材料与操作顺序，系统不代发、不登录、不采购。
> 前置：工作单七项就绪全过（当前 C3 为 **6/7**，只差 `platform_evidence`）。

## 0. 发布前 3 件事（缺一不可）

1. **真实打开样品**：用 Excel 或 WPS 打开 `docs/validation/product-workflow/b7/sample-study-planner-v1.xlsx`，确认 5 表 / 50 公式 / 下拉 / 打印正常 → 结论填进工作单 `sample_ref`。
2. **确认平台条件**：在闲鱼查「电子表格/学习资料」类目是否允许、虚拟交付方式、是否需要资质 → 把条款 URL 或截图编号填进 `platform_evidence`（**不要填 synthetic**）。
3. **定档与售后**：从 ¥9.9–19.9 / 29.9–39.9 / 49.9–69.9 三档选一档；确认售后/退款口径。

完成后工作单应显示 **7/7 通过**，导出按钮可用。

## 1. 导出上架包

1. 打开 http://127.0.0.1:5015/worksheet → 进入 `wo:c3-prod-20261023`；
2. 点 **「导出 Markdown（买家可见）」** 或 **「导出 JSON」** —— 这是**预览**，不写库；
3. 点 **「记录本次导出」**（CSRF 保护）→ 写入 1 行导出记录，页面显示“上次导出：有效 + 时间 + sha 前缀”。

> 若仍 409：说明 `platform_evidence` 为空，先做第 0.2 步。**不要**用 synthetic 地址绕过。

## 2. 闲鱼发布步骤（手动）

| 步骤 | 操作 | 注意 |
| --- | --- | --- |
| 1 | 选类目 | 优先「学习资料/电子文档」类；若平台只允许实物类目，**不要发布**，回来记录原因 |
| 2 | 填标题 | 用 `LISTING.md` §1 的 **标题 A**：`学习计划 Excel 模板｜课程/考试倒计时/周计划/复习进度（单文件）` |

| 5 | 图片 | 至少 1 张**真实截图**（Excel 里打开的表页）；**不要**用网图/他人模板图；不要放二维码/联系方式 |
| 6 | 交付方式 | 站内文件或平台允许的网盘；写明“拍下后发送文件”，不承诺即时/24h 等时限 |
| 7 | 售后说明 | 照抄 `LISTING.md` §5：范围/时限/退款未定，以平台规则为准；不含代做代填 |

## 3. 敏感词/表述避雷（来自 B8 PLATFORM-RULES 摘录）

- **不要写**：包过 / 保证提分 / 稳赚 / 官方认证 / 永久更新 / 内部渠道 / 代做代写 / 盗版 / 虚假原价。
- **不要做**：诱导站外交易、发联系方式/二维码、虚假发货、承诺效果或分数。
- **可以写**：表结构、公式数量、打印版式、示例数据可删、需要什么软件（均可被样品证明）。

## 5. 常见返工

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 导出 409 | `platform_evidence` 为空 | 回第 0.2 步补真实依据 |
| 页面显示“上次导出已失效” | 改了 `copy_version` / 货源 / revision | 重新点「记录本次导出」 |
| 平台审核不通过 | 类目错/敏感词/虚拟商品限制 | 记录原因到发布回填表，回阶段 4 改文案或换类目 |
| 买家说打不开 | 软件版本/文件损坏 | 走售后说明的“协助”范围，不做代做 |
