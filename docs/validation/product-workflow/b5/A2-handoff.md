# A2｜如果授权我代搭：权限边界、日志与回退

**待用户选择后执行**

> 这份文件只在一种情况下有用：你**明确决定**让执行者（AI）进到你的 Notion 里，按 [A1-build.md](A1-build.md) 代搭模板。
> **目前没有任何授权**：本文不是授权书，也不代表执行者已有访问权。你不选这条，就按 [A1-build.md](A1-build.md) 自己搭。

## 1. 代搭需要的授权（最小范围）

| 需要什么 | 具体做法 | 不需要什么 |
| --- | --- | --- |
| 一个**专用页面**的编辑权 | 在 Notion 新建一个空白页面（如 `A-学习笔记模板 a-v1`），只把这个页面共享/邀请给执行者，或把 integration 只加到这一页 | 不需要 workspace 管理员、不需要全库访问、不需要你账号的密码 |
| 明确的开始与结束时间 | 你告诉我"现在可以开始 / 到几点结束" | 不需要长期常驻授权 |
| 日志存放位置 | 指定一个页面（或就用 `06 示例数据` 旁边新建 `_搭建日志`） | 不需要你提供私人资料 |

**授权怎么给（两种，任选其一）**：
1. **共享页面**：页面右上 `Share` → 邀请执行者（或你操作的账号）为 `Can edit`。
2. **Integration**：在 Notion 设置里创建 integration，只把它加到这一个页面（`Connections` → 选该页面）。

**撤销怎么给**：见 §6，一步就能停。

## 2. 我会做什么（仅限这些）

1. 在你指定的那个页面下，按 [A1-build.md](A1-build.md) 新建 **7 个子页面**。
2. 在这 7 页里新建 **4 个数据库**、**38 个属性**、**3 组双向 relation**、**7 个视图**。
3. 建 **3 个核心页面模板**（课程/课堂/复习卡）与作业检查清单正文。
4. 填入 [A1-build.md](A1-build.md) §6 的**合成示例数据**（虚构课程/课堂/复习/作业）。
5. 写 `00 开始使用` 正文（复制步骤、字段说明、版本 `a-v1`、含/不含）。
6. 每完成一个阶段，在日志里写一条记录（§4），并向你回报"做了什么、页面在哪、哪项检查过了"。

## 3. 我不会做什么（硬边界）

| 不做 | 说明 |
| --- | --- |
| **不绑定、不接触任何支付** | 不加收款方式、不填银行卡、不点任何付费/订阅按钮；你的账单与我不发生关系 |
| **不发布、不分享、不公开** | 不点 `Publish to web`、不生成公开链接、不把页面分享给第三方、不发到任何平台 |
| **不导出、不下载你的私有内容** | 不导出 workspace、不下载你已有页面的正文/附件、不复制到我的环境 |
| **不读取与本任务无关的页面** | 只在你指定的那个页面子树里操作；不搜索、不浏览你的其它笔记/数据库 |
| **不改你已有的内容与设置** | 不动你原有的页面、不改 workspace/Teamspace 设置、不改成员与权限、不改你的模板库 |
| **不登录你的其它账号** | 不登录闲鱼/小红书/邮箱；不索取密码、验证码、Cookie |
| **不使用第三方素材** | 不引入第三方模板页面、字体、图标、图片；示例全部自制 |
| **不做承诺性文案** | 不写收益/销量/审核通过承诺（与 [copy-draft.md](../b4/copy-draft.md) 口径一致） |
| **不做自动化** | 不写脚本、不加 API、不设定时任务、不做 AI 生成 |

## 4. 操作日志（每次代搭都留痕）

在约定的日志页面（或 `_搭建日志`）里，**每完成一个阶段**追加一行：

| 时间（本地） | 阶段 | 动作 | 页面路径 | 结果 | 备注/失败项 |
| --- | --- | --- | --- | --- | --- |
| `2026-10-24 10:05` | §1 页面 | 新建 7 个子页面 | `A-学习笔记模板 a-v1/00…06` | 成功 | — |
| `2026-10-24 10:20` | §2 数据库 | 建 Courses + 9 属性 | `…/02 课程库` | 成功 | Rollup 省略（套餐不支持） |

- 每次会话结束，再给一条**汇总**：新建/修改的页面清单（可点开的链接）、未完成项、需要你决定的事项。
- 日志只写"做了什么"，不抄你的私人内容。

## 5. 回退方式（逐项可逆）

| 我做过的事 | 怎么退 | 影响 |
| --- | --- | --- |
| 新建的 7 个子页面 | 选中 → `Move to Trash`（或归档） | 我的全部产出一起消失；你原有内容不受影响 |
| 某个数据库/属性/视图/模板 | 在库里删掉对应项（属性列菜单 → `Delete property`；视图 → `Delete view`；模板 → 模板菜单 → 删除） | 只影响这一项 |
| 示例数据 | 全选行 → 删除 | 结构（属性/视图/关系）保留 |
| relation | 属性菜单 → `Delete property`（会同时移除反向列） | 相关视图里的该列消失 |
| **最坏情况：全部重来** | 把整个 `A-学习笔记模板 a-v1` 页面归档/删除 | 回到你授权前的状态（你自己的页面一直在别处，未被动过） |

- 回退**由你执行或由我按你指令执行**；我不擅自删除任何东西。
- 如果你要"只删一部分"，我会先给你"我建过的页面清单"，你圈定范围。

## 6. 撤销授权（随时、立即）

1. **共享方式**：页面右上 `Share` → 找到执行者 → `Remove`（或把权限改成 `Can view`）。
2. **Integration 方式**：Notion 设置 → `Connections` → 该 integration → 移除这个页面的连接（或直接删除 integration）。
3. 撤销后我**立即失去**访问；已建好的内容**留在你的空间**，不会自动删除（要删按 §5）。

> 撤销不需要理由、不需要提前通知；撤销后我不会再读写该页面。

## 7. 交付验收（与自建同一套标准）

代搭完成后，按 [A1-build.md](A1-build.md) §9 的 **5 项自测**逐项验收，并把结果写进日志：

1. Duplicate 可复制（另一个空白 workspace 复制后 7 页/4 库/视图都在）；
2. relation 双向正确（课程 ↔ 课堂 ↔ 复习三组都能双向看到）；
3. 视图筛选正确（勾选完成/改状态后条目消失；本周课程只含本周）；
4. 示例可删不影响结构（删掉示例后属性/视图仍在）；
5. 手机端可读（390 宽下表格可滑动、不串行）。

任一项不过 → 我修，不交付；修不动就按 [DECISION.md](../b4/DECISION.md) §2 的退出条件处理（**2 个工作日**内做不到可复制样张即停止，不投入美化）。

## 8. 需要你先确认的 4 件事

| # | 待确认 | 为什么必须你先定 |
| --- | --- | --- |
| 1 | 用哪个 workspace、哪个页面做根 | 决定我的操作范围（只在这个子树里） |
| 2 | 授权方式（共享页面 / integration）与时间窗 | 决定我能做什么、做到什么时候 |
| 3 | 是否允许我填合成示例数据 | 有人希望自己填；不允许就只建空结构 |
| 4 | 日志放哪、是否需要每次会话后即时汇总 | 便于你随时核对与回退 |

> 这 4 项没定之前，我不会开始；也不会用"先做后说"的方式绕过。
