# B｜向模板作者请求书面授权：邮件草稿 + 判断表

**待用户选择后执行**

> 只在选了 B 路线（向现有作者求授权）时使用。**执行者不会替你发信、不联系作者、不注册账号**；这封邮件由你自己发出。
> 依据：[DECISION.md](../b4/DECISION.md) §3-B（谈判对象与退出条件）、[candidates.json](../b2/candidates.json) 的 `github-studysphere`（MIT 覆盖范围未确认）。
> 提醒：拿到"MIT"不等于拿到"Notion 页面/封面可转售"，所以邮件里要逐项问清楚，别只问一句"能商用吗"。

## 1. 发信前先确认 3 件事

| # | 先确认 | 怎么确认 |
| --- | --- | --- |
| 1 | 你联系的是**模板作者本人**（不是搬运号） | 从模板页/仓库的署名、主页链接、提交记录确认；拿不准就先问"你是这个模板的作者吗" |
| 2 | 你能说清**要哪一份** | 模板名称 + 链接 + 版本号（如 `StudySphere 1.0.0`）；别只说"你那个模板" |
| 3 | 你愿意等 **7 天** | B 路线的最短周期是等回复，不是制作时间；等不了就直接走 A |

## 2. 邮件草稿（可直接复制，替换 `[]` 里的内容）

```text
主题：咨询《[模板名称]》的商业使用与转售授权（v[版本号]）

你好 [作者名]：

我是 [你的称呼]，在 [模板页面/仓库链接] 看到你做的《[模板名称]》（v[版本号]），
结构很清晰。我想把它改写成中文版，在闲鱼上作为学习笔记模板出售，
所以想先征得你的书面同意，而不是先上架再补。

想请你确认三件事（分别回答即可）：

1) 商业使用：是否允许我把这个模板用于销售用途？
2) 再分发：是否允许我把复制链接/文件发给购买者？
3) 转售：是否允许我以付费形式出售（含改写后的中文版）？

另外两点想一并确认：

4) 授权范围：是否覆盖模板的**页面正文**与**封面/图片素材**？
   如果只覆盖其中一部分，请告诉我哪部分不能用，我会替换。
5) 署名与版本：你希望我怎样标注作者与来源（例如"结构参考 [作者名]《[模板名]》v[版本号]"）？
   后续我如果做修订版，是否需要同步告诉你？

如果你不方便授权，或这不在你允许的范围内，直接告诉我就可以，
我不会再追问，也不会使用你的页面或素材。

回复期限：如果 7 天内没有收到回复，我就按"未获授权"处理，不再等待。

谢谢你的时间。

[你的称呼]
[联系方式]
```

- 全文没有收益承诺、没有"一定能卖出去"之类的话，也没有暗示对方"必须同意"。
- 邮件里"7 天"是**你自己的处理期限**（到期按未授权处理），不是给对方施压的 deadline。

## 3. 邮件要点覆盖自查（发前对一遍）

| 必须写到 | 在草稿里的位置 | 有没有 |
| --- | --- | --- |
| 用途：闲鱼转售学习笔记模板 | 开头第 2 段 | ✅ |
| 三档许可：commercial / redistribute / resell | 编号 1)、2)、3) | ✅ |
| 覆盖范围：页面正文 + 封面素材 | 编号 4) | ✅ |
| 模板版本与署名方式 | 主题行 + 编号 5) | ✅ |
| 回复期限 7 天 | 倒数第 3 段 | ✅ |
| 不施压 / 允许拒绝 | "如果你不方便授权…直接告诉我就可以" | ✅ |
| 无收益承诺 | 全文 | ✅ |

## 4. 对方回复后的判断表

| 回复情形 | 判定 | 下一步 |
| --- | --- | --- |
| **三档全 yes + 范围覆盖正文与封面 + 署名方式明确** | B 路线可继续 | 保存原文（截图/邮件导出）→ 记录版本与署名要求 → 按 [DECISION.md](../b4/DECISION.md) §4 填 `license` 三档为 `yes`、`supply` 用作者/仓库 ID → 再做样品与上架准备 |
| **只允许自用（personal / academic use）** | **不可转售** | 退出 B 主路径：要么按 [A1-build.md](A1-build.md) 自制（A），要么换品类（C）；**不得**把"个人可用"当成"可卖" |
| **允许但要求分成 / 要授权费** | 条件式许可，未定价 | 记录报价与分成比例 → 交给你决定是否接受（这已超出本材料范围）→ 不接受就退出 B；**不先上架再谈价** |
| **同意三档但范围不清**（没说封面/素材/中文改写） | 视为**未覆盖** | 回信补问第 4)、5) 两点；补齐书面确认前不用于转售 |
| **只回一句"MIT 随便用"** | 不足 | 回信说明"MIT 覆盖的是仓库代码与文档，我需要确认 Notion 页面与封面素材"，请其明确；仍不明确 → 按未授权处理 |
| **7 天无回复** | 视为**未获授权** | 退出 B（[DECISION.md](../b4/DECISION.md) §2 退出条件）→ 转 A 或 C；不再催促 |
| **明确拒绝** | 结束 B | 退出 B，转 A/C；**不再就该模板联系对方**，也不使用其页面/素材 |
| **要求你先买一份再谈** | 采购决策 | 由你决定是否购买（本材料不代为采购）；购买≠获得转售权，仍需三档书面确认 |

> 任何情形下都**不先上架后补授权**，也不把"对方没回"解释成"默认同意"。

## 5. 发信后要留的证据（便于以后核对）

1. 邮件原文（你发出的那封）+ 发送时间；
2. 对方回复原文（截图或导出），尤其是三档与范围的原话；
3. 你据此填的结论：`commercial / redistribute / resell` 各是 yes/no/unknown，范围覆盖哪些、不覆盖哪些；
4. 版本号与署名方式（对方要求怎么写）。

> 这些证据属于 [DECISION.md](../b4/DECISION.md) §4 的 `license`/`supply` 项；没有书面回复就填 `unknown`，不要凭印象填 `yes`。

## 6. 边界

- 本材料**不代发邮件、不联系作者、不注册/登录任何平台**；也不替你判断法律问题（不替代法律意见）。
- 不承诺收益、不承诺审核通过、不承诺"拿到授权就一定能卖"。
- 如果作者要求删除/停止使用，按对方要求执行（含下架已发布内容）。
