# C｜换品类候选清单（只列不调研）

**待用户选择后执行**

> 这是"如果 A 路线不合适，还可以做什么"的**候选池**，不是推荐、不是结论。**下列 5 个品类一个都还没有调研**（未核验需求、未查许可、未比价、未上架）。
> 用法：你先圈定 1–2 个方向 → 再按 [DECISION.md](../b4/DECISION.md) §3-C 做一次 B2 式检索（来源/许可/样品/平台），核验通过才进入制作。
> 不要用"关键词里看到有人卖"当作需求或许可证据；也不要把本清单当成收益预期。

## 1. 候选品类（5 个，均为「未调研」）

### C1. AI 提示词包（Prompt Pack）

| 项 | 内容 |
| --- | --- |
| 交付形态 | 文本文件/Notion 页面/PDF：一组可复制的提示词 + 用法说明 + 示例输入输出 |
| 为什么可能适配 | 纯自制内容、无需第三方素材；单位制作成本低；容易做中文场景包 |
| 许可关注点 | 提示词**全部自写**才干净；若改造他人提示词（尤其来自付费课程/公众号）需先确认授权；平台对"AI 相关"可能有额外规则 |
| 样品可得性 | 可自制 3–5 条样例即可展示；无需采购 |
| 平台适配 | 虚拟文本类目通常可发；注意标题避免绝对化或承诺性表述（例如暗示"必定赚钱""保证结果"一类的说法） |
| 检索词（中文） | `AI 提示词 模板`、`提示词 合集 出售`、`ChatGPT 提示词 中文`、`提示词 包 学生` |
| 检索词（英文） | `prompt pack template`、`AI prompt library notion`、`prompt engineering cheat sheet` |
| 未调研 | 需求规模、同类价格、平台类目规则、是否有买家投诉风险——**全部未核** |

### C2. PPT / 演示模板

| 项 | 内容 |
| --- | --- |
| 交付形态 | `.pptx` 文件或模板包（封面页/目录页/图表页/结束页 + 使用说明） |
| 为什么可能适配 | 学生/职场通用；结构可复用；可做"论文答辩/课程汇报"细分场景 |
| 许可关注点 | 字体、图标、图片、版式若来自第三方模板站点，**不能默认可商用**；需逐项确认（字体授权尤其容易被忽略） |
| 样品可得性 | 自制 1 套 8–10 页即可；不需要采购 |
| 平台适配 | 文件体积/预览图要求需按平台规则；"包含字体"容易被判侵权，建议只给结构、注明字体需自备 |
| 检索词（中文） | `PPT 模板 答辩`、`课程汇报 PPT 模板`、`PPT 模板 可商用` |
| 检索词（英文） | `presentation template student`、`thesis defense slides template`、`pptx template commercial use` |
| 未调研 | 同类供给密度、价格带、字体授权现状——**未核** |

### C3. 学习计划表 / 复习清单（表格或 PDF）

| 项 | 内容 |
| --- | --- |
| 交付形态 | `.xlsx` / `.csv` / PDF：周计划表、考试倒计时表、复习清单（可打印） |
| 为什么可能适配 | 与 A 路线同人群（学生/自学者），但不依赖 Notion；交付更轻；可与 A 的字段结构复用 |
| 许可关注点 | 全部自制即可；若用第三方模板改格式需确认；不含第三方图标/字体 |
| 样品可得性 | 自制 1 张即可展示；无需采购 |
| 平台适配 | 电子表格类目常见；纸质打印件涉及物流，不在本清单范围 |
| 检索词（中文） | `学习计划表 excel`、`复习计划 模板 下载`、`考试倒计时 表格` |
| 检索词（英文） | `study planner spreadsheet`、`revision timetable template`、`exam countdown sheet` |
| 未调研 | 与免费资源（大量免费模板）的差异点、付费意愿——**未核**，这是本品类最大不确定项 |

### C4. 简历模板

| 项 | 内容 |
| --- | --- |
| 交付形态 | `.docx` / `.pptx` 简历模板（单页/双页 + 填写说明 + 常见错误清单） |
| 为什么可能适配 | 求职季需求集中；结构标准化；可做"应届生/实习"细分 |
| 许可关注点 | 版式与图标需自制；**不得**收集/展示真实他人简历做样例（隐私）；样例必须虚构 |
| 样品可得性 | 自制 2 版（应届/实习）即可；无需采购 |
| 平台适配 | 求职类目竞争激烈；注意平台对"代写/包过"类表述的限制（本清单不做代写服务） |
| 检索词（中文） | `简历模板 应届生`、`实习简历 模板 word`、`简历 排版 模板` |
| 检索词（英文） | `resume template student`、`cv template internship`、`ATS friendly resume template` |
| 未调研 | 同类免费供给量、差异化空间——**未核** |

### C5. 资料整理服务（服务型，风险最高）

| 项 | 内容 |
| --- | --- |
| 交付形态 | 服务：帮买家把散乱资料整理成结构化文档/表格（按次或按小时） |
| 为什么可能适配 | 客单价可能高于纯模板；可复用 A 的字段与流程经验 |
| 许可关注点 | 买家提供的资料可能含第三方版权内容，**整理≠获得分发权**；需在服务说明里写清"仅整理、不代为传播" |
| 样品可得性 | 需自造虚构样例（不能拿真实客户资料）；无采购 |
| 平台适配 | 服务类目规则最复杂（可能涉及"代做/代写"限制、交付验收争议）；**必须先看平台规则**，不确定就不选 |
| 检索词（中文） | `资料整理 服务`、`笔记整理 排版 服务`、`文档整理 代做`（注意：含"代做"字样的多为平台敏感词，仅作检索参考，不代表可发布） |
| 检索词（英文） | `document formatting service`、`notes organization service` |
| 未调研 | 平台是否允许、纠纷率、交付标准——**全部未核**；不建议作为首选 |

## 2. 统一判断标准（圈定方向后逐项打分）

| 判据 | 怎么算通过 | 不通过的后果 |
| --- | --- | --- |
| **许可三档**（commercial / redistribute / resell） | 全部可书面说明为"可"（自制内容=自己有处分权） | 任一为 no/unknown → 不能作为可售商品 |
| **样品可得性** | 能在 **2 个工作日**内做出可展示样品（自制或已获授权） | 做不出 → 按 [DECISION.md](../b4/DECISION.md) §2 退出该方向 |
| **平台适配** | 目标平台有对应类目、标题/交付方式不违规、虚拟交付路径清楚 | 类目不明或规则禁止 → 不选 |
| **自制可行性** | 不需要第三方字体/图标/模板/图片（或已获授权） | 需要 → 先解决素材许可，否则不算通过 |
| **需求证据** | 有可核对的需求代理指标（不是"看到有人卖"） | 只有关键词命中 → 视为**未核验**，不当作需求证据 |

## 3. 怎么用这份清单（不含结论）

1. 从 C1–C5 里圈 **1–2 个**你最愿意做的方向（兴趣、时间、已有素材都算理由）。
2. 对圈定的方向做一次 **B2 式检索**：来源清单 → 许可原文 → 样品/Duplicate 入口 → 平台条款，逐项留证据。
3. 按上表 5 条判据逐项写"通过/不通过/未核"；**任一未核就不进入制作**。
4. 通过后再回到 [A1-build.md](A1-build.md) 的同类做法（若仍是文档/模板类）或另写规格。
5. 2 个工作日内拿不出"许可清晰 + 可自制 + 平台有证据 + 可展示样品"的组合 → 暂停该方向，不硬凑（[DECISION.md](../b4/DECISION.md) §2 C 的退出条件）。

## 4. 本清单明确不包含

- 任何价格、销量、利润或收益预期，也不对"好不好卖"下判断；
- 任何已核验的货源、许可结论或平台条款结论（全部**未调研**）；
- 采购、联系商家、上架、发布动作；
- 对 A/B 两路线的替代性结论（选哪条由你在 [DECISION.md](../b4/DECISION.md) 的三路对照里定）。
