# 学习计划 / 考试复习表 · 买家使用说明（v1）

> 这是一个 **Excel（.xlsx）单文件**模板：把课程、考试、倒计时、周计划、复习进度放在一个文件里。
> 示例里的课程/考试/知识点**全是虚构的**，可以直接整行删掉换成你自己的。
> 本文件不含宏、不含外部链接、不含图片，也不含任何自动化或 AI 生成。

## 一、5 张表分别干什么

| 工作表 | 用途 | 你要填什么 |
| --- | --- | --- |
| `使用说明` | 版本、包含/不含、怎么改 | 不用填 |
| `课程与考试` | 一门课一行 | 课程名、教师、学分、考试日期、地点、备注 |
| `考试倒计时` | 自动算"还有几天考" | **不用填**，从 `课程与考试` 自动取数 |
| `周计划` | 周一至周日 × 时段 | 直接在格子里写安排（如"高等数学""复习：线代"） |
| `复习进度` | 一个知识点一行 | 知识点、所属课程、掌握度（下拉）、复习次数、下次复习 |

## 二、3 步开始用

1. **改课程**：打开 `课程与考试`，把 6 行示例改成你的课；`考试日期` 点单元格右侧日历选日期（日期格式为 `yyyy-mm-dd`）。没有考试的课，日期留空即可，倒计时表会显示"未排期"。
2. **排周计划**：打开 `周计划`，在对应星期与时段交叉的格子里写安排；打印前确认纸张为 **A4 纵向**（已设好打印区域与 1 页宽缩放）。
3. **记复习**：打开 `复习进度`，按知识点逐行写；`掌握度` 用下拉选 **生疏 / 一般 / 熟练**；`状态` 列会自动变成"今日复习 / 待复习 / 未排期"。

## 三、自动计算怎么读

| 位置 | 含义 |
| --- | --- |
| `考试倒计时!B1` | 今天（`=TODAY()`，每天打开自动变） |
| `剩余天数` | 考试日期 − 今天；**负数 = 已过考试日** |
| `状态` 四级 | `已过期`（<0）／`紧急`（≤3 天）／`临近`（≤7 天）／`正常`（>7 天），并按颜色标出 |
| `复习进度!状态` | 下次复习 ≤ 今天 → `今日复习`；有日期但未到 → `待复习`；没填日期 → `未排期` |
| 各表底部统计 | 课程门数/学分合计/有考试门数、紧急与已过期数、知识点数/熟练数/今日复习数/平均复习次数 |

> 改完日期或新增行后，若数字没变，按 **F9** 重算一次；或把该行公式向下拖动一格再拖回来。

## 四、打印

- 5 张表都已设**打印区域**；`周计划` 为 **A4 纵向、按宽度缩放到 1 页**，并重复打印标题行（表头）。
- 想打印"倒计时清单"：选中 `考试倒计时` → 打印，建议勾选"适应纸张"。
- 手机/平板上可用 Excel App 或 WPS 打开；显示可能与桌面略有差异，属正常。

## 五、常见问题

| 问题 | 处理 |
| --- | --- |
| 日期显示成一串数字（如 45678） | 选中该列 → 设置单元格格式 → 日期 → `yyyy-mm-dd` |
| `状态`/`剩余天数` 显示为空 | 该行 `考试日期` 为空（空=未排期）；填上日期即可 |
| 下拉里选不到"生疏/一般/熟练" | 该单元格的"数据验证"被删了；从相邻单元格复制格式，或重新设置下拉 |
| 删掉示例行后统计不对 | 统计公式按固定区域计算（3–8 行 / 3–10 行）；删行后在底部统计格里把区域改到你的实际范围即可 |
| 想加更多课程/知识点 | 在最后一行下面插入行 → 把上一行的公式向下拖动（倒计时表同理） |
| 打开时提示"受保护的视图" | 这是 Office 对下载文件的默认保护，点"启用编辑"即可；文件不含宏 |

## 六、包含 / 不包含

**包含**：5 张表、50 个公式（TODAY/IF/COUNTIF/SUM/COUNTA/AVERAGE）、条件格式（倒计时与状态着色）、掌握度下拉、打印区域与冻结首行、虚构示例数据。

**不包含**：第三方字体/图片/图标/模板；宏与自动化脚本；AI 生成；提醒推送；云同步；代做、代录入、代整理；持续更新；任何学习效果、考试成绩、销量或收益承诺。

- 示例数据为虚构占位，不含真实学校、教师或个人信息；如需对外展示，请先替换为你自己的内容。
