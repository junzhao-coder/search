## 5. "换品不改系统"要点

- 5 个机制逐项判断为**适用**：三栏界面、七项就绪、导出去重/版本戳、货源失效联动（改/停已选→许可同步+样品成本作废+409，恢复＝重新自检+重填成本）、复盘脚本与 CSV 字段。
- 新建入口两条（**与侧栏无关**）：① 打开 `/pick`，在目标商品行点「选这个」→ 自动建单并进入 `/source`；② 从零建自制商品时直接访问 `/worksheet/new`（侧栏无此入口，属保留的兼容路由）。侧栏只有 **选品 / 选源 / 起草介绍** 三项。
- 新单最小重填集合：规格 → 货源候选（`self:<新标识>` 并采用）→ 样品自检 → 成本（100 分=1 元）→ 平台证据 → 文案定稿。
