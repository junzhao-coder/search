# 三分支应对卡 + 替代交付形态（A/B/C 勾完之后照着做）

> 前置：先在 [b23/PLATFORM-DECISION.md](../b23/PLATFORM-DECISION.md) 里勾出你的结论（A 允许 / B 需资质 / C 不允许）。本卡只回答一件事：**勾完之后，明天做什么**。
> 三条通用红线（任何时候都适用）：
> 1. **未取得资质前不发布**（B 分支的核心）；
> 2. **不改类目、不改描述去规避审核**（C 分支的核心）；
> 3. 不虚构销量/评价/效果，不向买家索要账号密码验证码。
>
> 本文所有"需要什么证件/多少钱/多久"都标了 **未核验**——必须由你在发布页或平台规则里确认，本文不给结论。

## 0. 30 秒确认你该看哪张卡

| 你勾的结论 | 含义（b23 原文） | 去看 |
| --- | --- | --- |
| **A 允许** | 类目明确允许虚拟交付、无需额外资质、限制已知 | §1 |
| **B 需资质** | 类目允许但需要证件/保证金/权限 | §2 |
| **C 不允许** | 类目明确禁止虚拟商品，或找不到任何允许依据 | §3 |

## 1. A 分支卡：允许发布 —— 5 条动作

1. **把证据填回工作台**：`/copy?wo=<你的单号>` → 「录入证据」→ `目标平台条件证据` 填条款链接或截图编号 → 保存。**看到**：七项里 `platform` 转「通过」，阻断项清空。
2. **导出并记录**：点「导出 Markdown/JSON」→ 再点「记录本次导出」。**看到**：出现导出记录行（含 revision/版本戳）；重复点同版本不会新增行。
3. **按发布卡走 8 步**：打开 [b24/PUBLISH-CARD.md](../b24/PUBLISH-CARD.md)，照①～⑧做（确认类目、粘标题、粘详情、定价与"虚拟商品"标注、上传自制图、写交付方式与时效、发布）。**看到**：发布成功页给你的商品链接。
4. **立刻回填**：回 `/copy` 的「发布回填」→ 状态=已发布、填链接、发布时间、已售=0、平台备注写类目路径与审核情况 → 保存。**看到**：状态徽章变「已发布」，链接与已售出现。
5. **记一行反馈 + 等 7 天**：在 [b25/feedback-log.csv](../b25/feedback-log.csv) 记一行（曝光没有就写 `na`，成交写 0）；**满 7 天**再跑 `python review.py feedback-log.csv` 看 4 个数字。**看到**：脚本给出四选一建议或"样本不足，保留观察期"。

**停止条件（任一出现就停下，不要硬发）**
- 发布页出现「需要资质 / 类目不符 / 禁止发布虚拟商品」提示 → 立即停止，改判 **B** 或 **C**；
- 七项里任一项从「通过」退回「未通过」（例如换了货源）→ 先恢复证据，再谈发布；
- 发布后 7 天内出现平台警告/下架通知 → 停止继续推广，按通知整改或转 C。

## 2. B 分支卡：需资质 —— 5 条动作

> 核心原则：**资质没到手之前，`platform_evidence` 保持为空、不发布**；也不要用"改类目/换描述"绕过资质要求。

### 2.1 可能涉及的证件/权限（**均为未核验**，只给量级）

| 可能要什么 | 获取路径（去哪办） | 时间量级（未核验） | 成本量级（未核验） |
| --- | --- | --- | --- |
| 实名认证 | 平台内「我的 → 实名认证」 | 分钟～1 天 | 通常 0 |
| 类目发布权限申请 | 发布页「申请类目权限」/ 平台客服 | 1～7 天 | 未核验（可能 0，也可能要保证金） |
| 保证金 | 类目入驻页缴纳 | 当天可缴 | 金额按类目，**未核验** |
| 营业执照（若要求企业主体） | 市场监管部门线上/线下办理 | 数个工作日～数周 | 未核验（含注册地址等） |
| 出版物经营许可证（仅当商品被认定为"出版物"） | 属地新闻出版/文化主管部门 | 数周～数月 | 未核验 |
| 品牌/版权授权书（若卖他人 IP 相关物） | 权利人出具 | 取决于对方 | 取决于对方报价 |

> 上表只用来"知道大概有哪些门"，**具体要不要、要哪种、多少钱、多久，必须在发布页与平台规则里核对并留证**（做法见 [b23/PLATFORM-CHECKLIST.md](../b23/PLATFORM-CHECKLIST.md) ③）。

### 2.2 办证 vs 换品：自己判断的问题清单（本文不替你决定）

按顺序回答，写在一张纸上；**答完你自己就能看出来**：

1. 这个证件我**已经有**吗？（有 → 直接补证据转 A；没有 → 继续）
2. 它是否要求**企业主体**（营业执照/对公账户/注册地址）？我有没有？
3. 一次性投入（办证 + 保证金 + 可能的地址费用）大概是多少？我能承受吗？
4. 办下来要等多久？**等待期间我的店是空转的**吗？
5. 这个资质是**只对这一类目有效**，还是能覆盖我后面几个品？
6. 我预计这类商品**一个月能成交几单**？（拿不出数字就先别投钱）
7. 有没有**同等需求的替代形态**（见 §4）能立刻开卖、不用资质？
8. 如果 30 天后资质还没下来，我的**退出方案**是什么？

### 2.3 动作（5 条）

1. **暂停发布**：把该单状态留在「未发布」，`目标平台条件证据` 继续留空；**不要**为让导出变绿去填不实链接。
2. **登记 B 结论**：在 `PLATFORM-DECISION.md` 勾「B. 需资质」，把"要哪种证件/多少钱/多久"写成具体条目并留证（截图/条款链接）。
3. **算一次账**：用 §2.2 的问题清单算出"办证总成本"和"等待期损失"，写在备注里。
4. **同时开一条并行线**：按 §4 选一个**不需要资质**的替代形态，新建工作单（入口见 §5），先把它推到"七项就绪"。
5. **定期回看**：每周固定一天回看资质进度；拿到资质 → 补证据转 A；明确拿不到 → 转 C 或换品。

**停止条件**
- 资质要求**无法在你能接受的时间/成本内满足** → 停止 B，转 C 或换品；
- 平台明确回复"个人号不可发布该类虚拟商品" → 立即停止，不再尝试；
- **任何时候都不做**：借他人资质、买证、改类目/改描述规避审核。

## 3. C 分支卡：不允许 —— 4 条动作

1. **停止该品**：该单不再导出、不再尝试发布；在 `PLATFORM-DECISION.md` 勾「C. 不允许」并写明依据（条款原文/截图编号）。
2. **不做规避动作**：**不改类目、不改描述、不拆词、不写暗号**去骗过审核——这类做法一旦被判定，账号风险远大于收益。
3. **选一个出口**：① 换**替代交付形态**（见 §4，改成 PDF/表格/文本包等）；② 或直接**换品**（换需求相近但类目允许的东西）。
4. **新建工作单继续走流程**：入口见 §5；新形态同样要过七项就绪、导出记录、复盘（脚本不变）。

**停止条件**
- 除非拿到**新的、明确的"允许"证据**（条款变更/客服书面答复），否则不再重试发布；
- 出现"换个名字就能发"的念头时 → 停，这正是要避免的规避。

## 4. 三个替代交付形态（四项评估）

> 三个形态都**不需要新建样品**；下面是形态与改造成本评估，**不是已做好的商品**。平台类目风险一律 **未核验**（要按 b23 五核对点自己查）。

### 4.1 PDF / 打印版资料

| 评估项 | 结论 |
| --- | --- |
| **交付物形态** | 单个 PDF（A4，可打印）：如"学习计划表打印版 + 填写说明"，买家自己打印或平板批注 |
| **许可是否天然可控** | **是**（内容全自制、只嵌系统默认字体；不用第三方图片/图标即可）。若引用他人资料则不再天然可控 |
| **平台类目风险** | **未核验**。虚拟/文档类目是否允许 PDF 交付、是否被认定为"出版物"（可能触发出版物相关资质），必须按 b23 ③ 核对 |
| **改造成本** | **低-中**：可从 [b7 的 xlsx 样品](../b7/sample-study-planner-v1.xlsx) 导出/排版成 PDF；需补"打印说明"页；**不需要重做内容**，但要重新做一次样品自检（PDF 仅校验文件头） |

### 4.2 表格工具（xlsx 模板）

| 评估项 | 结论 |
| --- | --- |
| **交付物形态** | `.xlsx` 单文件（多工作表 + 公式 + 下拉 + 打印区域），买家改课程/日期即用 |
| **许可是否天然可控** | **是**（只用系统默认字体 + 纯色/边框，无图片/图标；这是 b7 已采用的路线） |
| **平台类目风险** | **未核验**。电子表格/文档模板类目是否允许虚拟交付需核对；标题避免任何绝对化或承诺性表述 |
| **改造成本** | **最低**：[b7 样品](../b7/sample-study-planner-v1.xlsx) 可直接复用（5 表/50 公式），只需按新品类改名与改示例数据；**不用重做** |

### 4.3 纯文本提示词包

| 评估项 | 结论 |
| --- | --- |
| **交付物形态** | 一个 `.md`/`.txt` 文本包：如"10 条复习计划提示词 + 用法 + 2 个示例输出"（配合买家自己的 AI 工具使用） |
| **许可是否天然可控** | **是**（全部自写）；**但**若改写他人提示词（课程/公众号/付费包）则**不再可控**，需先取得授权 |
| **平台类目风险** | **未核验**。AI/提示词类目可能存在额外表述限制；「代做/代写」以及任何以通过率或效果作承诺的说法属禁区 |
| **改造成本** | **中**：需要新写内容（不能直接从 b7 搬），但格式最简单（纯文本，自检只看 UTF-8 与行数）；**无需图片与排版** |

**三个形态怎么选（一句话）**：想最快开卖 → 4.2（复用现有样品）；想更像"资料"、便于打印 → 4.1（从 xlsx 导出）；想避开表格/文档类目 → 4.3（但要新写内容）。

## 5. 换品不改系统：机制怎么复用

结论：**换形态或换品，只需要"新建一张工作单 + 重填证据"**，系统机制不用改。

| 机制 | 对新形态是否适用 | 说明 |
| --- | --- | --- |
| 三栏界面（选品 / 选源 / 起草介绍） | **适用** | 同一套页面；新单照旧走"选品→选源→文案" |
| 七项就绪检查 | **适用** | 规格、货源、许可三档、样品、成本、平台证据、文案——新形态逐项重填；`platform_evidence` 必须是你自己核到的证据 |
| 导出去重与版本戳 | **适用** | 同一版本重复"记录本次导出"不新增行；改内容/换货源后旧导出会失效，需重导 |
| 货源失效联动 | **适用** | 改/停**已选**货源 → 许可同步、样品与成本作废、导出 409；恢复＝重新自检 + 重填成本（见 [b17/MANUAL.md](../b17/MANUAL.md) 环节 2/3/5） |
| 复盘脚本 | **适用** | [b25/review.py](../b25/review.py) 与 CSV 字段不变，新形态照样记 4 个数字 |

**新建入口（两条，用途不同）**
1. **从已有机会建单**：打开 **`/pick`**，在目标商品那一行点 **「选这个」** → 自动建单并跳到 **`/source`**（接着选货源）。
2. **从零建自制商品**（不挂在某条机会上）：直接访问 **`/worksheet/new`**（本机 `http://127.0.0.1:5015/worksheet/new`）——**侧栏没有这个入口**，它是保留的兼容路由。

> 侧栏只有 **选品 / 选源 / 起草介绍** 三项；`/worksheet/...` 这类地址要自己输或从页面内链接进入，别在侧栏里找。

**新单要重填的最小集合**：规格（名称/用途/交付物/平台）→ 货源候选（自制写 `self:<新标识>` 并采用）→ 样品自检（新文件路径）→ 成本（100 分 = 1 元）→ 平台证据（新类目核对结果）→ 文案定稿。

## 6. 三条通用提醒

1. **建议不等于平台结论**：本卡与工作台都只做机械判断，平台是否允许由平台决定；
2. **未核验就别当结论**：所有"要什么证/多少钱/多久/类目是否允许"都要你自己核对并留证；
3. **别为了变绿造假**：填不实链接、改类目、改描述，短期过检、长期是账号风险。
