## 2. exit 码缺陷与修复

- 缺陷：此前 search 模式 `exit_code` 只看 `completed`，导致 `loads=0 + stopped=timeout + records=[]` 也返回 0；**7 次 exit=0 全部不能作为成功证据**（第三次同类缺陷）。
- 修复（`tools/selection/xhs_probe.py` `exit_code`）：
  - `stopped` 含 risk/captcha/dom → **exit 5**；
  - `stopped` 其它非空（如 nav timeout）→ **exit 6**；
  - `stopped=null` 但 `records` 为空 → **exit 6**；
  - 仅 `completed=True && stopped=null && records 非空` → **exit 0**。
- stub 覆盖（`tests/test_selection_xhs_probe.py::test_search_exit_code`）：clean→0、captcha→5、dom→5、nav timeout→6、records 空→6、not completed→6；本批 15 项 probe 单测通过。
