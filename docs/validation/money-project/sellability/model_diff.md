# model.md 变更：七维 + 可售性

> 自 `2026-10-22` 起，评分模型从六维改为七维。旧六维公式、缺失值处理和排序规则不变，仅新增一维并把原六维按 **0.85** 等比缩放。

## 权重表

| 指标 | 旧权重 | 新权重 | 缩放 |
| --- | --- | --- | --- |
| 需求强度 demand_strength | 0.30 | **0.255** | ×0.85 |
| 竞争稀疏度 competition_sparsity | 0.20 | **0.170** | ×0.85 |
| 毛利空间 gross_margin | 0.20 | **0.170** | ×0.85 |
| 履约容易度 fulfillment_ease | 0.10 | **0.085** | ×0.85 |
| 合规安全度 compliance_safety | 0.10 | **0.085** | ×0.85 |
| 可复制性 replicability | 0.10 | **0.085** | ×0.85 |
| **可售性 sellability** | — | **0.150** | 新增 |
| 合计 | 1.00 | **1.00** | 0.255+0.170×2+0.085×3+0.150 = 1.000 |

公式不变：`total = Σ(w_i × norm_i) / Σ(w_i)`；缺失指标同时从分子/分母剔除。新增可售性始终有值。

## 可售性规则

| 档位 | 分值 | 触发（不区分大小写） |
| --- | --- | --- |
| 高 | 0.80–1.00 | 显式售价 `¥/$/价格/售价/selling for/sold for`、购买入口（链接/扫码/私信购买/下单/buy/checkout）、商品化词（合集/素材包/模板包/教程包/bundle/pack/collection） |
| 低 | 0.00–0.20 | `free`（排除 free shipping）、`giveaway/giving away`、`免费/领取/抽奖/赠送/求推荐/有没有/推荐一下/求模板/谁有`；`送` 仅在“免费送/送出/送模板/送资料”等短语命中 |
| 中性 | 0.40–0.60 | 其余 |

- 售价 + 购买入口 → **0.95**；仅售价 → **0.85**；仅购买入口/商品化词 → **0.80**。
- 免费词 + 购买入口 → **0.90**，reason 写明冲突；免费词 + 售价但**无购买入口** → **0.10**，reason 写明冲突。
- 纯 free/赠送 → **0.10**；无信号 → **0.50**。
- 闲鱼 `platform=xianyu` 或带 `price` 的条目 → **0.55**，reason 写明“闲鱼标价为引流价（¥1 类），有价格但不可当真实售价”。

## 误伤处理

- `\bfree\b(?!\s*(shipping|ship|delivery))`：`free shipping` 不命中；`freedom` 因词边界不命中。
- `送` 不裸匹配，避免“发送/发给你”误伤；使用“免费送/送出/送模板/送资料/包送”等短语。
- 价格必须带币种/价格词/`selling for`，避免普通数字误判。

## 输出字段

新增：`sellability_raw`、`sellability_norm`、`sellability_weighted`、`sellability_reason`。`scores.csv` 为 39 列（原 35 + 4）。

## 旧测试修正

`tools/test_scoring.py` 的“缺需求”覆盖率从 0.70 改为 **0.745**（1 − 0.255），因为六维缩放后非需求权重为 0.745；不是删断言。
