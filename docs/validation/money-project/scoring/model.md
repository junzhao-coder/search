# 机会评分模型（Notion 模板 / 数字商品）

> 本模型用于把 X、Bilibili、GitHub 的公开样本转成可解释、可复算的机会排序。
> 它是**筛选器**，不是收入预测；所有毛利均为区间估计（缺成本输入）。

## 1. 样本与单位

- 观测单位：一条 X 推文、一个 B 站视频、一个 GitHub 仓库。
- 本轮样本：X 30 条（`notion template`, f=top）、B 站 20 条（同关键词）、GitHub 10 仓库（`notion template`, stars 排序）。
- 采集时间：`2026-10-22T06:57Z` ~ `2026-10-22T07:02Z`；原始数据在 `raw/`，统一记录在 `items.jsonl`。
- 评分只使用原始公开字段（互动/播放/star、标题、许可证），不抓取私域数据、不读取 cookie。

## 2. 七个指标与权重

> 新增 **可售性 sellability（0.15）**；原六维按 **0.85** 等比缩放，合计仍为 1.00。旧六维公式不变，仅加一维。

| 指标 | 权重 | 方向 | 原始值（raw） | 归一化（0–1） |
| --- | --- | --- | --- | --- |
| 需求强度 demand_strength | **0.255** | 越高越好 | X: likes+retweets+replies；B站: play；GitHub: stars | 平台内 `log1p(raw)` 的百分位 |
| 竞争稀疏度 competition_sparsity | **0.170** | 越高越好 | 平台供给先验 + 同作者重复惩罚 | `1 - clamp(prior + penalty)` |
| 毛利空间 gross_margin | **0.170** | 越高越好 | 公开售价区间 − 估计履约成本 | 区间中值（0–1），并保留 low/high |
| 履约容易度 fulfillment_ease | **0.085** | 越高越好 | 交付形态规则 | 直接 0–1 |
| 合规安全度 compliance_safety | **0.085** | 越高越好 | IP/许可证/话术风险规则 | 直接 0–1 |
| 可复制性 replicability | **0.085** | 越高越好 | 模板/代码/视频制作难度规则 | 直接 0–1 |
| 可售性 sellability | **0.150** | 越高越好 | 售价/购买入口/商品化词 vs free/赠送/求推荐 | 规则分档 0.1/0.5/0.8–0.95/0.55 |

权重合计 **1.00**（0.255+0.17+0.17+0.085+0.085+0.085+0.15 = 1.0；保留三位小数）。

## 3. 归一化与公式

### 3.1 需求强度（平台内百分位）

对平台 \(p\) 的 \(n_p\) 个样本，按 `log1p(raw)` 升序排序；第 \(i\) 条的归一化值为：

\[
d_i = \frac{\text{rank}_p(\log(1+raw_i))}{n_p - 1}
\]

- 最低为 0，最高为 1；并列取首个位置（tie 规则固定）。
- 平台内归一化避免 GitHub stars（万级）压过 B 站 play（千级）与 X 互动（百级）。
- **跨平台不可直接比较绝对热度**；只比较“在本平台样本中的相对需求”。

### 3.2 竞争稀疏度

公开样本没有全市场竞品计数，因此用**可解释的供给先验**：

\[
competition = clamp(prior_p + 0.05 \times \max(0, sameAuthorCount_p - 1), 0, 1)
\]
\[
competition\_sparsity = 1 - competition
\]

| 平台 | prior | 解释 |
| --- | --- | --- |
| X | 0.60 | 模板卖家/免费模板贴密集 |
| Bilibili | 0.45 | 教程多、直接卖模板的供给相对少 |
| GitHub | 0.70 | 开源仓库密集、同质化高 |

同作者重复最多罚 0.20。该指标是**样本先验**，不是市场竞品实测。

### 3.3 毛利空间（缺成本输入，区间估计）

没有真实成本/售价成交数据；按平台与标题规则给出**假设区间**，`margin_mid = (low+high)/2`：

| 类型 | 售价假设 | 履约成本假设 | margin low/high/mid | 依据 |
| --- | --- | --- | --- | --- |
| X 数字模板 | $9–49 | $0.5–3 | 0.70 / 0.95 / **0.825** | 支付/托管/交付近乎零边际成本 |
| X 服务/咨询 | $50–200 | $10–40 | 0.50 / 0.85 / **0.675** | 人力交付 |
| B站模板/课程 | ¥15–99 | ¥5–30 | 0.45 / 0.80 / **0.625** | 制作+答疑 |
| B站普通内容 | 无直接售价 | 内容制作 | 0.35 / 0.70 / **0.525** | 广告/联盟变现代理 |
| GitHub 仓库 | $19–99/月 | $2–20 | 0.45 / 0.85 / **0.65** | 托管/支持/服务化 |

**明确标注**：`margin_low/high` 是假设区间，`margin_mid` 仅用于评分；没有成本输入，不得当作真实利润或报价。

### 3.4 履约容易度 / 合规 / 可复制性（规则）

- 履约：X 数字模板 0.90；X 服务 0.55；B站模板 0.75；B站普通视频 0.60；GitHub 0.80。
- 合规：X 普通 0.80；含 “AI side hustle/passive income/guarantee” 0.55；含 “resell/clone/免费/破解” 0.65；B站模板 0.80、普通 0.75、含盗版/破解词 0.55；GitHub MIT/Apache/BSD 0.90、GPL/AGPL 0.75、NOASSERTION 0.55、无许可证 0.50。
- 可复制：X 0.85；B站模板 0.70、普通 0.55；GitHub 普通 0.70、awesome-list 0.80。

### 3.5 可售性 sellability（新增，纯函数）

规则不区分大小写，按标题/URL/作者文本匹配：

| 档位 | 分值 | 触发 |
| --- | --- | --- |
| 高 | 0.80–1.00 | 显式售价（`¥/$/价格/售价/selling for/sold for`）、购买入口（链接/扫码/私信购买/下单/buy/checkout）、商品化词（合集/素材包/模板包/教程包/bundle/pack/collection） |
| 低 | 0.00–0.20 | `free`（排除 `free shipping`）、`giveaway/giving away`、`免费/领取/抽奖/赠送/求推荐/有没有/推荐一下/求模板/谁有`；`送` 仅在“免费送/送出/送模板/送资料”等短语命中，避免“发送”误伤 |
| 中性 | 0.40–0.60 | 无以上信号 |

- **冲突处理**：免费词与售价/购买词同时出现时，按**是否存在购买入口**决定——有购买入口按高（0.90）并写明冲突；无购买入口按低（0.10）并写明冲突。
- **误伤防护**：`\bfree\b` 加负向断言排除 `free shipping`；`\bfreedom\b` 不命中；`送` 不匹配裸字，避免“发送”。
- **闲鱼引流价**：`platform=xianyu` 或带 `price` 的条目给 **0.55**，reason 写明“闲鱼标价为引流价（¥1 类），有价格但不可当真实售价”；不进 scoring items 的 60 条样本，仅规则单测覆盖。
- 可售性只影响总分，不改变既有六维公式；旧六维按 0.85 缩放。

## 4. 总分与缺失值

\[
total = \frac{\sum_i w_i \cdot norm_i}{\sum_i w_i \quad (i \in present)}
\]

- 指标为 `null`/缺失：从**分子和分母同时剔除**，`weight_coverage = Σ present weights`；不把缺失当 0，也不伪造。
- 本轮 60 条七项指标均有值（`missing_metrics` 为空）；毛利是“估计值”，不是“缺失”。可售性规则值始终有值。
- 排序：`total_score` 降序；并列按 `item_id` 升序；无随机数，重复运行结果一致。

## 5. 字段与复算

`items.jsonl` 每条含：

```json
{
  "platform": "x|bilibili|github",
  "item_id": "...",
  "title": "...", "url": "...", "author": "...", "published_at": "...",
  "metrics": {"source": "...", "demand_raw": 123, "demand_basis": "...", "raw": {}},
  "collected_at": "...", "raw_ref": "raw/...", "raw_summary": {}
}
```

`scores.csv` 每行保留：各指标 raw、norm、weighted、`sellability_reason`、`total_score`、`rank`、`weight_coverage`、`missing_metrics`、`margin_assumption`、`source`、`raw_ref`。可按本文公式从 items 复算。

## 6. 适用边界

1. **样本小且非概率抽样**：X f=top 30、B站 20、GitHub 10，不能代表全市场；平台内百分位只在本样本内有效。
2. **需求是代理指标**：点赞/播放/star 受历史累积、推荐算法、语言/地区影响；不等于付费意愿。
3. **毛利是假设区间**：无成本输入；实际利润取决于定价、退款、支付费率、客服与流量成本。
4. **竞争是样本先验**：不是竞品数量/关键词难度实测；同作者重复惩罚只处理样本内集中。
5. **合规规则是启发式**：不构成法律意见；Notion 模板转售、GitHub 许可证、AI 收益承诺均需逐项复核。
6. **优先数字商品**：样本以模板/教程/开源工具为主；没有观察到需要囤货/重售后的品类，因此榜单不覆盖该类机会（覆盖不足，非“无机会”）。
